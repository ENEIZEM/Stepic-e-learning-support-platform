# Платформа поддержки электронного обучения Stepic

Учебный мультимедийный ресурс на HTML, CSS и Vanilla JavaScript.

## Запуск

Откройте `index.html` в современном браузере. Сборка и установка зависимостей не требуются. Файлы Three.js и Vanta.NET находятся в корне репозитория и подключаются локально.

## Структура

- `index.html` — титульная страница, навигация и 17 учебных страниц.
- `css/site.css` — оформление титульной страницы и основного интерфейса.
- `js/app.js` — hash-навигация, боковое содержание, Vanta.NET и интерактив страницы 5.1.
- `fonts/` — локальные файлы шрифта Onest и лицензия.
- `three.r134.min.js`, `vanta.net.min.js` — локальные скрипты анимации первой страницы.

Ресурс не использует сервер, базу данных или регистрацию. Ответы учебного интерактива обрабатываются в браузере.
